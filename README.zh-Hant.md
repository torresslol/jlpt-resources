## 一份簡單的備考節奏

1. **先背單字，再學文法。**依級數過一遍單字表，再一個一個學文法。
2. **限時寫一回完整考古題**（含聽力），找出最弱的部分。
3. **依題型專項練習。**重點練失分最多的部分，每題都看解析。
4. **按計畫複習錯題。**隔幾天再寫一次，而不是只看一遍。
5. **考前幾週再寫一回整份考古題**，估一下分數。

## OK JLPT 能做什麼

- **備考：**單字卡片分 N5–N1，文法一課一課學，先看講解再做小測；可以設考試日期、估分。
- **考古題與專項：**歷屆考古題依年份、級數整回作答，含聽力；專項每做一題，立刻看解析。
- **錯題複習：**錯題依遺忘規律安排複習，並列出這些題考到的單字和文法。
- **筆記與 AI：**題目下有同學寫的巧解、口訣、陷阱提醒；某個句子為什麼這樣選，直接問 AI。
- **跨裝置同步：**同一個帳號，iPhone、iPad、網頁之間進度和錯題即時同步。
