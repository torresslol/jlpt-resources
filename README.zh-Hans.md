## 一份简单的备考节奏

1. **先背词，再学语法。**按等级过一遍单词表，再一个一个学语法点。
2. **限时做一套完整真题**（含听力），找出最弱的部分。
3. **按题型专项练习。**重点练丢分最多的部分，每题都看解析。
4. **按计划复习错题。**隔几天再做一次，而不是只看一遍。
5. **考前几周再做一套整卷**，估一下分数。

## OK JLPT 能做什么

- **备考：**单词卡片分 N5–N1，语法一课一课学，先看讲解再做小测；可以设考试日期、估分。
- **真题与专项：**历年真题按年份、等级整套作答，含听力；专项练习每做一题，立刻看解析。
- **错题回炉：**错题按遗忘规律安排复习，并列出这些题考到的词和语法。
- **笔记与 AI：**题目下有考友写的巧解、口诀、避坑经验；某个句子为什么这样选，直接问 AI。
- **多设备同步：**同一个账号，iPhone、iPad、网页之间进度和错题实时同步。
